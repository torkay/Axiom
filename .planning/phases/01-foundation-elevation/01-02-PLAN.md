  <action>
    Generate elevation maps using massiv parallel computation:

    1. In src/Axiom/Geo/Elevation.hs:
       - Import Data.Massiv.Array as A
       - Import qualified Axiom.Geo.Noise as Noise
       - Implement generate function:
         ```haskell
         generate :: Int -> ElevationMap
         generate seed =
           let grid = A.computeAs U $ A.makeArray Par (Sz2 512 512) $ \(i :. j) ->
                 let x = fromIntegral i / 512.0
                     y = fromIntegral j / 512.0
                     -- Scale noise from [-1,1] to [0,1] for elevation
                     noise = (Noise.terrainNoise x y + 1.0) / 2.0
                 in noise
           in ElevationMap { emGrid = grid, emSeed = seed }
         ```
       - Add sample function: sample :: ElevationMap -> (Int, Int) -> Double
         - Use A.index' to sample from grid: A.index' (emGrid em) (i :. j)
       - Export: generate, sample

    2. In src/Main.hs:
       - Import Axiom.Geo.Elevation as Elev
       - Generate elevation map: let elevMap = Elev.generate 42
       - Sample center point: let centerElev = Elev.sample elevMap (256, 256)
       - Print: "Generated 512x512 elevation map, center elevation: " ++ show centerElev
       - Create World with elevation: let worldWithElev = WithElevation elevMap EmptyWorld
       - Print: "World advanced to HasElevation phase"

    Use Par (parallel) strategy for massiv array generation (per research).
    Use computeAs U (unboxed array) for memory efficiency (per research).
    Add STRICT fields (already done in Plan 1) to prevent space leaks.
    Scale noise from [-1,1] to [0,1] for valid elevation range.
    DO NOT use nested lists [[Double]] (causes O(n) access and poor cache performance).
