2. Implement `baseTemperature :: Double -> Double` that calculates sea-level temperature from latitude using solar angle formula:
   - Equator (0°): 27°C
   - Poles (±90°): -20°C

   - Takes elevation (meters) and latitude (degrees)

   - Use strict unboxed arrays (`Array U`) to avoid lazy evaluation performance issues

Add module documentation explaining the physics: temperature decreases with elevation (lapse rate) and with distance from equator (solar angle).

WHY avoid custom formulas: The lapse rate and solar angle formulas are internationally verified standards.   <name>Task 2: Implement precipitation module with elevation effects</name>
  <files>src/Axiom/Climate/Precipitation.hs</files>
  <action>
Create Axiom.Climate.Precipitation module that adjusts base precipitation (from noise) based on elevation:

1. Implement `adjustPrecip :: Double -> Double -> Double` that modifies precipitation based on elevation:
   - Takes basePrecip (from noise, in cm/year) and elevation (meters)
   - Returns adjusted precipitation in cm/year
   - Model: precipitation increases up to mid-elevation (~2000m), then decreases above
   - Formula from research:
     ```haskell
     let midElev = 2000.0
         factor = if elevation < midElev
                  then 1.0 + (elevation / midElev) * 0.5  -- +50% at mid-elevation
                  else 1.5 - ((elevation - midElev) / midElev) * 0.3  -- decrease above
     in basePrecip * factor
     ```
   - This models orographic precipitation (moisture rises, cools, condenses)
2. Implement `precipitationField :: Array U Ix2 Double -> Array U Ix2 Double -> Array U Ix2 Double` for grid-based computation:
   - Takes base precipitation grid (from noise) and elevation grid
   - Returns adjusted precipitation grid
   - Use `M.zipWith adjustPrecip` for element-wise application
   - Use strict unboxed arrays (`Array U`)
3. Add documentation explaining rain shadow concept and why mid-elevations get more precipitation

Note: This is a simplified model. Full rain shadow modeling (with wind direction) is deferred - for v1, we model elevation effects only. The research notes that sophisticated wind patterns are Phase 4+ complexity.

WHY this formula: Orographic precipitation is well-established meteorology. Moisture-laden air rises up mountains, cools, condenses (rain/snow on windward side), then descends dry (rain shadow on leeward). Our simplified model captures elevation effect without full wind simulation.
