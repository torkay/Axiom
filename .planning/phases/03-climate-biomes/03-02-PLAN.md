Create biome classification system using Whittaker diagram:

1. In `src/Biome/Types.hs`, define BiomeType GADT or data type:
   ```haskell
   data BiomeType
     = TropicalRainforest
     | TropicalSavanna
     | Desert
     | TemperateRainforest
     | TemperateForest
     | Grassland
     | Taiga
     | Tundra
     deriving (Show, Eq)
   ```

2. In `src/Biome/Whittaker.hs`, implement `classifyBiome :: Double -> Double -> BiomeType` using Whittaker diagram thresholds from research:
   - Input: temperature (°C), precipitation (cm/year)
   - Output: BiomeType
   - Thresholds (from research - do NOT modify these):
     ```haskell
     classifyBiome temp precip
       -- Tropical (temp > 20°C)
       | temp > 20 && precip > 200 = TropicalRainforest
       | temp > 20 && precip < 50  = Desert
       | temp > 20 && precip < 100 = TropicalSavanna

       -- Temperate (10°C < temp < 20°C)
       | temp > 10 && temp < 20 && precip > 150 = TemperateRainforest
       | temp > 10 && temp < 20 && precip > 75  = TemperateForest
       | temp > 0  && temp < 10 && precip < 100 = Grassland

       -- Cold (temp < 0°C)
       | temp < 0 && precip > 50 = Taiga
       | temp < 0 && precip < 50 = Tundra

       -- Catch-all for edge cases
       | otherwise = Desert
     ```
   - These thresholds are from the Whittaker biome diagram verified in research

3. Implement `biomeField :: Array U Ix2 Double -> Array U Ix2 Double -> Array U Ix2 BiomeType` for grid-based classification:
   - Takes temperature grid and precipitation grid (from Plan 1)
   - Returns biome grid
   - Use `M.zipWith classifyBiome` for element-wise application

4. Add module documentation explaining Whittaker diagram and why we use these specific thresholds

WHY these exact thresholds: The Whittaker diagram is the standard for mapping climate → vegetation type, based on 40+ years of ecology research. Custom biome rules miss established knowledge and produce unrealistic distributions. These thresholds have been verified across all climate zones globally.
