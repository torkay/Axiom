**JSON.hs** - Thin wrapper around Aeson (already used in 04-01):
```haskell
{-# LANGUAGE StrictData #-}
module Axiom.Export.JSON where

import Data.Aeson (encode, decode)
import qualified Data.ByteString.Lazy as BL
import Axiom.Simulation.State (WorldState)

exportWorldJSON :: WorldState -> FilePath -> IO ()
exportWorldJSON world path = BL.writeFile path (encode world)

importWorldJSON :: FilePath -> IO (Maybe WorldState)
importWorldJSON path = decode <$> BL.readFile path
```

No custom ToJSON instances needed - WorldState already has Generic derivation from 04-01. This is just a convenience wrapper.

**ASCII.hs** - Render world state as ASCII map:
```haskell
{-# LANGUAGE StrictData #-}
module Axiom.Export.ASCII where

import Data.Text (Text)
import qualified Data.Text as T
import qualified Data.Text.IO as TIO
import Axiom.Types.Biome (BiomeType(..))
import Axiom.Climate.Climate (ClimateCell(..))
import qualified Data.Massiv.Array as M

renderASCII :: M.Array M.U M.Ix2 ClimateCell -> Text
renderASCII climateGrid = T.unlines (rows <> [legend])
  where
    M.Sz2 height width = M.size climateGrid
    rows = [renderRow y | y <- [0..height-1]]
    renderRow y = T.concat [tileChar (climateGrid M.! M.Ix2 y x) | x <- [0..width-1]]
    tileChar cell = case climateBiome cell of
      TropicalRainforest -> "T"
      TemperateForest -> "t"
      BorealForest -> "^"
      Grassland -> "."
      Desert -> "~"
      Tundra -> "*"
      Shrubland -> "s"
      Savanna -> "S"
    legend = "\nLegend: T=Tropical, t=Temperate, ^=Boreal, .=Grassland, ~=Desert, *=Tundra, s=Shrubland, S=Savanna"

exportWorldASCII :: M.Array M.U M.Ix2 ClimateCell -> FilePath -> IO ()
exportWorldASCII grid path = TIO.writeFile path (renderASCII grid)
```

Use the existing ClimateCell type from Phase 3 which contains biome data. Render based on BiomeType using single ASCII characters.
