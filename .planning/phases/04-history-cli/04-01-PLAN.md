**Common pitfalls to avoid**:
- Polymorphic parser types (kills performance)
- Long alternative chains without factoring (backtracking death)
- Using `many satisfy` instead of `takeWhileP` (100x slower)
- Deep monad stacks (stick to single State or StateT IO)

**AST.hs** - Define simple Universal Law syntax:
```haskell
{-# LANGUAGE DeriveGeneric #-}
{-# LANGUAGE StrictData #-}
module Axiom.DSL.AST where

import Data.Text (Text)
import GHC.Generics (Generic)

data Law = Law Text Expr deriving (Show, Generic)
data Expr
  = Var Text
  | Const Int
  | Add Expr Expr
  | If Condition Expr Expr
  deriving (Show, Generic)

data Condition
  = Equals Expr Expr
  | GreaterThan Expr Expr
  deriving (Show, Generic)
```
Add Generic instances for JSON serialization (for 04-02).

**Lexer.hs** - Follow RESEARCH.md example exactly:
- Define `type Parser = Parsec Void Text` (concrete type for performance, per Pitfall 2)
- Space consumer `sc` handles whitespace and `--` line comments, `{- -}` block comments
- Lexeme wrapper `lexeme = L.lexeme sc`
- Symbol parser `symbol = L.symbol sc`
- Identifier parser using `takeWhileP` (NOT `many satisfy`, per Pitfall 3)
- Reserved keywords helper: ["law", "if", "then", "else"]

**Parser.hs** - Implement grammar:
- Top-level: `universalLaws = sc *> many law <* eof`

- Avoid deep backtracking - factor common prefixes per Pitfall 1

Example DSL:

Use `errorBundlePretty` for user-facing parse errors (per Pitfall 6). Don't return raw error types.

```haskell
module Axiom.Simulation.State where

import qualified Data.Map.Strict as Map
import Data.Map.Strict (Map)
import Control.Monad.State.Strict (State)
import GHC.Generics (Generic)

data WorldState = WorldState
  { _civilizations :: Map CivID Civilization
  , _currentYear :: Int
  , _events :: [HistoricalEvent]
  } deriving (Show, Generic)

data Civilization = Civilization
  { _civPopulation :: Int
  , _civTechnology :: Int
  , _civLocation :: (Int, Int)  -- tile coordinates
  } deriving (Show, Generic)

type CivID = Int
data HistoricalEvent = TechMilestone CivID Int Text
  deriving (Show, Generic)

type Simulation a = State WorldState a
```
