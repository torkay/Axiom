module Axiom.Types.Hydrology where

import Data.Massiv.Array (Array, Ix2, U)
import Data.Graph.Inductive.Graph (Gr)

-- Flow direction to one of 8 neighbors
data FlowDirection = N | NE | E | SE | S | SW | W | NW | NoFlow
  deriving (Eq, Show, Ord)

-- Cell data for drainage network nodes
data CellData = Cell
  { cellPos :: Ix2
  , elevation :: Double
  , accumulation :: Int  -- Number of upstream cells
  } deriving (Eq, Show)

-- Flow data for drainage network edges
data FlowData = Flow
  { flowVolume :: Double
  } deriving (Eq, Show)

-- Drainage network as graph (Node = cell, Edge = flow direction)
type DrainageNetwork = Gr CellData FlowData

-- Basin identified by outlet position and member cells
data Basin = Basin
  { outletPos :: Ix2
  , memberCells :: [Ix2]
  , area :: Int
  } deriving (Eq, Show)

-- River extracted from high flow accumulation
data River = River
  { path :: [Ix2]  -- Ordered from source to mouth
  , length :: Int
  , sourcePos :: Ix2
  , mouthPos :: Ix2
  } deriving (Eq, Show)
```

module Axiom.Geo.Hydrology
  ( priorityFlood
  , fillDepressions
  ) where

import Data.Massiv.Array as M
import Data.PSQueue (PSQ)
import qualified Data.PSQueue as Q
import qualified Data.Set as Set
import Data.Massiv.Array (Array, Ix2, U, Sz(..), (!))

type ElevationGrid = Array U Ix2 Double

-- Fill depressions using Priority-Flood algorithm (Barnes et al. 2014)
-- O(m log² m) where m is number of cells
priorityFlood :: ElevationGrid -> ElevationGrid
fillDepressions :: ElevationGrid -> ElevationGrid  -- Alias for clarity
```

**Algorithm from RESEARCH.md:**
1. Initialize priority queue with border cells (sorted by elevation)
2. Mark border cells as processed
3. While queue not empty:
   - Pop cell with lowest elevation
   - For each unprocessed neighbor:
     - If neighbor elevation < current elevation: raise neighbor to current elevation (fill depression)
     - Add neighbor to queue with its (possibly raised) elevation
     - Mark neighbor as processed
4. Return modified elevation grid

**Implementation details:**
- Use PSQ Ix2 Double for priority queue (cell position keyed by elevation)
- Use Set Ix2 for processed cells tracker
- Border cells: all cells on grid edges (row 0, row max, col 0, col max)
- Neighbors: 8-connected (N, NE, E, SE, S, SW, W, NW) - check bounds
- When raising elevation, use `max neighborElev currentElev` to ensure monotonic increase
- Use massiv's delayed arrays (D representation) for intermediate computations, manifest (U) for final result

**What to avoid:**
- Don't use custom priority queue - PSQueue is O(log n) and proven
- Don't process all cells at once - queue ensures lowest-to-highest elevation order
- Don't skip raising step - this is what fills depressions
- Don't forget to check grid bounds for neighbors

Follow code example structure from RESEARCH.md Priority-Flood pattern (lines 247-263).

Add helper functions:
